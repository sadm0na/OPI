\doxysubsection{Detailed Description}
Главный модуль программы 

Программа выполняет следующие действия для каждой строки входного файла\+:
\begin{DoxyItemize}
\item Разбивает строку на слова
\item Находит слова с min/max количеством гласных
\item Меняет их местами
\item Сохраняет результат в новый файл 
\end{DoxyItemize}
