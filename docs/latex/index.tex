\chapter{Программа обработки строк, считанных из файла}
\hypertarget{index}{}\label{index}\index{Программа обработки строк, считанных из файла@{Программа обработки строк, считанных из файла}}
\hypertarget{index_purpose}{}\doxysection{\texorpdfstring{Назначение}{Назначение}}\label{index_purpose}
Программа обрабатывает текстовый файл, находит в каждой строке слова с минимальным и максимальным количеством гласных, меняет их местами и сохраняет результат в текстовый файл.
