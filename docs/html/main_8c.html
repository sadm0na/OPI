Detailed Description

Главный модуль программы

Программа выполняет следующие действия для каждой строки входного файла:

  • Разбивает строку на слова
  • Находит слова с min/max количеством гласных
  • Меняет их местами
  • Сохраняет результат в новый файл

Parameters
argcКоличество аргументов командной строки
argvМассив аргументов (ожидается имя входного файла)
Returns
Код возврата:
  • OK (0) в случае успеха,
  • Отрицательные значения при ошибках (см. ReturnCodes)
Warning
Ограничения:
  • Максимальная длина строки: STR_LEN символов
  • Максимальная длина слова: WORD_LEN символов
  • Максимальное количество слов в строке: WORD_NUMBER

Пример использования:

./app.exe func_tests/data/pos_01_in.txt
Note
Результат сохраняется в файл func_tests/scripts/answer.txt
